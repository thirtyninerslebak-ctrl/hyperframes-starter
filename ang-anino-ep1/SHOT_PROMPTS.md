### Swapping real clips into the edit
1. Save each generated clip as `assets/shots/shotNN.mp4` (e.g. `shot09.mp4`), trimmed to the shot's length.
2. Run `npm run build`. Any shot with an `.mp4` now uses the video instead of the still.
3. Add recorded dialogue/narration as `<audio>` clips or mix them into `audio/soundtrack.wav`.
4. `npm run render`, then `npm run final`.
